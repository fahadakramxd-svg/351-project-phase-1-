# 351-project-phase-1-
Design &amp; configure a Cisco Packet Tracer network linking 2 campus WAN sites. WAN 1 (Main) &amp; WAN 2 (Branch) each have 2 LANs, and each LAN contains 3 end devices. Ensure static routing or OSPF is configured so any PC in WAN 1 can successfully transmit data packets to any PC in WAN 2.
